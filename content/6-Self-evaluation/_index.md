During my internship in the **AWS First Cloud AI Journey (FCAJ)** program from **September 14, 2026** to **December 6, 2026**, I had the opportunity to learn, practice, and apply my academic background in Information Security to a real-world cloud engineering environment.  
As part of a 5-member project team, I participated in designing, developing, testing, and deploying **PhishGuard AI** — a Human-in-the-Loop Multi-Channel Phishing Triage & SOAR Copilot built on AWS Serverless. Through this end-to-end capstone journey and participating in four technical community events, I significantly strengthened my skills in **cloud architecture design, Infrastructure as Code (AWS SAM), serverless security (IAM Least Privilege, Cognito RBAC, AWS WAF, S3 Object Lock), Generative AI integration (Amazon Bedrock, RAG, Guardrails), technical specification writing, and cross-functional teamwork**.

In terms of work ethic, I consistently strived to deliver high-quality work on schedule, adhered to program guidelines, actively sought mentor feedback, and collaborated closely with teammates to resolve complex security and engineering edge cases.
