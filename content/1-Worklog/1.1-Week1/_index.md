### Week 1 Objectives:

* **Onboarding & Processes:** Familiarize with the First Cloud AI Journey (FCAJ) working environment, internal regulations, communication channels, and internship reporting workflows.
* **AWS Cloud Fundamentals:** Gain an overview of cloud computing concepts and the core AWS service ecosystem.
* **Account & Cost Management:** Set up an AWS account, understand AWS Free Tier policies, and explore the $200 AWS Credits program.
* **Hands-on Practice:** Gain practical experience by deploying foundational labs on the AWS Management Console.
* **Project Research:** Explore standout FCAJ projects from previous cohorts to shape ideas for the team's capstone project.
* **Team Formation:** Form a 5-member project team, establish collaboration rules, and assign initial roles.

### Week 1 Achievements:

* Mastered the rules, workflows, and official support channels of the FCAJ program.
* Built a solid foundation in AWS Cloud concepts and cloud system architecture design thinking.
* Understood the roles and use cases of core AWS services:
  * **Compute:** EC2, AWS Lambda (flexible and serverless compute).
  * **Storage:** S3, EBS (object and block storage).
  * **Database:** Amazon RDS (managed relational database).
  * **Networking:** VPC (isolated virtual private networking).
  * **Security:** IAM (identity and access management).
  * **AI/ML:** Amazon Bedrock (building Generative AI applications).
  * **Management & Monitoring:** CloudWatch, AWS Budgets (observability and budget control).
* Completed the $200 Credits hands-on labs on the AWS Console, grasping basic workflows for EC2, Bedrock, Lambda, RDS, and Budgets.
* Understood AWS cost management principles and configured alerts to prevent unexpected charges.
* Absorbed practical project design patterns by analyzing top-performing projects from prior cohorts.
* Successfully formed a 5-person team and established initial communication and collaboration workflows.
