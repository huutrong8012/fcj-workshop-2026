This section documents our 11-week internship and capstone project journey in the **AWS First Cloud AI Journey (FCAJ)** program (from **September 14, 2026** to **November 27, 2026**). Over this period, our 5-member team progressed from foundational AWS cloud training and hands-on labs to designing, building, testing, and deploying **PhishGuard AI** — a Human-in-the-Loop Multi-Channel Phishing Triage & SOAR Copilot on AWS Serverless.

Each weekly worklog outlines our key objectives, daily tasks, technical references, and concrete achievements across the 11 weeks:

**Week 1:** [Onboarding, AWS Cloud Fundamentals, $200 Credits Labs, and Team Formation](1.1-week1/)

**Week 2:** [IAM Least Privilege, Serverless Event-Driven Foundations, and PhishGuard AI Ideation](1.2-week2/)

**Week 3:** [Step Functions Orchestration, AWS SAM, Bedrock (RAG & Guardrails), and S3 Object Lock](1.3-week3/)

**Week 4:** [Edge Security (CloudFront & WAF) and PhishGuard AI End-to-End Architecture Design (v1.0)](1.4-week4/)

**Week 5:** [Deterministic Policy Engine, PII Redaction Rules, RAG Corpus, and Cost Estimation (v2.1)](1.5-week5/)

**Week 6:** [Design Security Audit, Technical Specification Upgrade (v2.2), and Architecture Refinement](1.6-week6/)

**Week 7:** [UI/UX Wireframing, API Contract Standardization, and SES Domain / Bedrock Setup](1.7-week7/)

**Week 8:** [Core Logic Prototyping (PII Redactor, URL Defanger, Policy Engine) and AWS SAM Base](1.8-week8/)

**Week 9:** [MVP Phase 1: Core Infrastructure Deployment, Early Risk Validation, and Ingestion Pipeline](1.9-week9/)

**Week 10:** [MVP Phase 2: Extract & Redact, Triage, Bedrock Synthesize, and Human-in-the-Loop Approval](1.10-week10/)

**Week 11:** [MVP Phase 3 & Final Delivery: React Web Portal, AWS WAF, 15 Test Cases, Workshop, and Demo](1.11-week11/)
